> **Licence note (checked 2026-10-07):** Barry Launcher is GPL-2.0 (its `LICENSE`; its README says GPL-2.0, like pb-os). Touch Master is MIT. Comparing the two: the only construct identical by inspection is a one-line coordinate flip (`raw_to_screen`), which is just the panel's physical orientation; Barry's code has no matching momentum/friction implementation, and its sensor discovery (env-var overrides, `_first()` lookups) differs from the plugin's fixed paths and globs. So MIT is kept and Barry is credited as inspiration. If you know more of Barry's code was reused, the plugin must become GPL-2.0-compatible: open an issue.
