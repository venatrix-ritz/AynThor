# AynThor — research repo + Thor tooling (AYN Thor + Armada OS)

Source-grounded knowledge base on the AYN Thor and Armada OS, plus the small amount of code built from it: `tweaks/` (device tweak scripts, deployed over SSH) and `plugins/thor-input/` (Decky plugin "Touch Master"). Start at [README.md](README.md); rules for writing docs are in [docs/reference/CONVENTIONS.md](docs/reference/CONVENTIONS.md) (claim tags, Sources section, no unsourced causal claims, today's date absolute).

- **Upstream clones** live in `refs/` (gitignored): `scripts/clone-refs.ps1` rebuilds them; SHAs in `refs/MANIFEST.md` + `scripts/refs.lock.json`. Cite as `refs/<dir>@<sha7>:path#Lnn`. Never edit `refs/`.
- **GitHub exports** in `refs/_gh/` (`scripts/fetch-gh-meta.ps1`) are the primary source for Armada release history/issues/PRs; WebFetch output is secondary.
- **Subagents cannot see `G:\`** via Read/Grep/Write — use Bash `G:/...` paths. Heredocs in Bash tool calls with mixed quotes failed once; use the Write tool per file. `python3` is not on the Bash PATH here; use `python`.
- **Line endings:** Linux-bound files (`tweaks/`, `*.sh`, `*.service`, `*.py`) are pinned to LF by `.gitattributes`. This machine has `core.autocrlf=true`; never let CRLF reach the Thor.
- **Device access:** SSH key auth only (`armada@<ip>`, IP changes; Armada Tools → Remote Access shows it). Ven installed passwordless sudo on the Thor on 2026-10-03/04 and said system changes are fine, but the Thor was **reset afterwards**: the key, sudoers entry and every mod are gone until Ven re-authorizes. No LAN scanning. Do not edit sudoers, signature policy or system packages yourself — give Ven the command. `docs/hardware/device-observed.md` is a 2026-10-03/04 snapshot only.
- **Tweak scripts (`tweaks/`)** are community-sourced and mostly untested on this hardware — see the provenance note in `tweaks/README.md`. Deploy with `tweaks/apply-all-tweaks.sh [--audio|--battery|--system|--lighting|--status] [HOST]`. `--all` omits the stick-RGB daemon because Armada already ships `armada-rgb`.
- **Git:** branches `main` → `docs/software-deep-dive` → `feat/decky-thor-input` → `fix/audit-*` form one line of history; no remote. Branch for every change, merge `--no-ff`, commit messages end with the Co-Authored-By line.
- **Audit state (2026-10-07):** docs written by an Antigravity session were not fully re-verified; unsourced ones carry an audit banner (`dual-screen-on-android`, `partition-layout`, `components`, `artemis`). Whether barry-launcher was ever fully installed is **unverified** (only its two missing deps were unpacked in user space; `community-tools.md` records a later reflash that removed them). Coverage gaps and unanswered questions: [docs/reference/open-questions.md](docs/reference/open-questions.md).
