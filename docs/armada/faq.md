# FAQ (project-documented)
> Scope: upstream FAQ · Researched: 2026-10-03 · Confidence: high

- **Nintendo layout:** Steam Settings → Controller → *Use Nintendo Button Layout* swaps A/B and X/Y.
- **Prompts don't match device:** enable *Universal Face Button Glyphs* there.
- **Power profiles not applying:** Armada Control's Power tab only edits profiles; activate via Steam QAM → Performance → Performance Profile.
