# Armada Store (Decky plugin)
> Scope: store categories/status per docs · Researched: 2026-10-03 · Confidence: high

Pre-installed Decky plugin (QAM → Decky → Armada Store). Categories: **Emulators**, **Applications**, **Decky Plugins**. Installed entries show Installed / Update icons; installed apps become **non-Steam shortcuts** (add to Steam from the entry). [src: refs/upstream/armadaos.dev@26dcfc3:docs/using-armada/armada-store.md]

Thor-relevant: the Store carries preconfigured **DRM-leasing builds of melonDS and Azahar** for the second display (20260907 notes — [release-history](release-history.md)). Desktop mode has a separate app store, **Bazaar**. [src: refs/upstream/armadaos.dev@26dcfc3:docs/using-armada/desktop-mode.md]
