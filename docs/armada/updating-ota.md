# Updating Armada (OTA)
> Scope: update channels and behaviour as documented · Researched: 2026-10-03 · Confidence: high (docs)

- Updates run in place from Steam's system settings — no reflash, no redownloading games. [src: refs/upstream/armadaos.dev@26dcfc3:docs/getting-started/updating.md]
- **Beta** (recommended; post release-testing) vs **Preview** (every commit on `main`; may be incomplete); switch under Settings (Preview may need Developer Mode + "Show Advanced Update Channels"). [src: refs/upstream/armadaos.dev@26dcfc3:docs/getting-started/updating.md] [src: refs/upstream/armadaos.dev@26dcfc3:docs/getting-started/preview-images.md]
- Warning: OTA is "new and still being validated"; "you may need to reflash if an update fails." Home page advertises rollback to a previous version. [src: refs/upstream/armadaos.dev@26dcfc3:docs/getting-started/updating.md] [src: refs/upstream/armadaos.dev@26dcfc3:docs/index.md]
