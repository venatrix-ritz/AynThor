# Armada Control (Decky plugin)
> Scope: tabs/features per user docs · Researched: 2026-10-03 · Confidence: high

QAM → Decky tab → **Armada Control**; five tabs: [src: refs/upstream/armadaos.dev@26dcfc3:docs/using-armada/armada-control.md]
1. **Compatibility** — per-game resolution + FEX preset (Default / Fast / Compatible / Custom), saved per game.
2. **Power** — edit **Eco / Balanced / Performance** (each = fan curve + CPU underclock + GPU clock range). Editing only; activate in Steam QAM → Performance. [src: refs/upstream/armadaos.dev@26dcfc3:docs/troubleshooting/frequently-asked-questions.md]
3. **Fan Control** — graphical curve editor; save, then assign the curve to a profile in Power.
4. **RGB** — on-device LEDs where supported.
5. **Settings** — controller emulation (Xbox 360 / Xbox Series / Steam Deck / DualSense), stick+trigger calibration, system options, **Plasma Mobile** toggle ([desktop-mode](desktop-mode.md)).

Release-note context: power profiles in QAM (20260621), fan-curve editor + RGB (20260907), "Armada Tools" app (20260926) — [release-history](release-history.md).
