# Desktop Mode
> Scope: documented desktop switching · Researched: 2026-10-03 · Confidence: high

Steam power menu → **Switch to Desktop** = KDE Plasma; **Bazaar** and **Armada Installer** live here; **Return to Gaming Mode** shortcut switches back. **KDE Plasma Mobile** (touch-friendly) is toggled in Armada Control → Settings. [src: refs/upstream/armadaos.dev@26dcfc3:docs/using-armada/desktop-mode.md]

Thor dual-screen behaviour (desktop spans both screens; Plasma Mobile on the bottom screen in Game Mode) is in release notes only — [release-history](release-history.md), [thor-changelog](thor-changelog.md).
