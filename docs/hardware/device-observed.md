## External-monitor freeze (#529)
Issue #529 (OS `20260915`, kernel 7.2.3) blamed a missing `ucsi_pmic_glink` module. On this unit (OS `20260926`, kernel 7.2.6): `CONFIG_UCSI_PMIC_GLINK=y`, `CONFIG_QCOM_PMIC_GLINK=y`, `CONFIG_TYPEC_UCSI=y` (built in, not modules; only `ucsi_ccg.ko` exists under `/lib/modules/7.2.6/…/ucsi/`), and a `ucsi-source-psy-pmic_glink` power supply is registered, i.e. the driver is present and bound. **Not tested:** whether plugging a monitor still freezes (nothing was connected — a deliberate non-action). So "module missing" does not hold for 7.2.6; the freeze itself is unconfirmed either way. [observed] [src: refs/_gh/issues.json#529]
