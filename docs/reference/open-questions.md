**Problems found:**
1. `tweaks/lighting/stick-led-color.py` is **byte-identical** (762 lines, 0 differing lines) to `system_files/usr/libexec/armada/stick-led-color` on Ga1dz1's fork branch `stick-rgb-lighting` — a script for the **Retroid Pocket Mini V2** — with no attribution or licence note in `tweaks/` (Armada is GPL-2.0-or-later). Armada upstream also already ships `packages/armada-rgb` with an AYN Thor profile and an RGB tab in Armada Control, so a second service writing the same LEDs is a conflict risk.
2. `tweaks/system/setup-device-fixes.sh` step 2 is a no-op: it greps `"name": "DSI-2"` but `kwinoutputconfig.json` uses `connectorName`; it never changes anything yet ends with "System fixes applied cleanly!". Step 3 prints `active` as a fallback even if no zram swap exists.

5. `thor-display-sync.service` orders `After=` two **user** units (`gamescope-session-plus@steam`, `armada-bottom-gamescope`), which has no effect in a system unit; harmless.
6. `/var/local/bin` is used for "OSTree compliance"; on Fedora-based ostree/bootc images `/usr/local` normally links to `/var/usrlocal` and is writable, so this may be unnecessary [unverified on device].
